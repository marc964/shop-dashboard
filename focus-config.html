How to create the token (one-time, ~2 minutes)
  1. Open github.com/settings/personal-access-tokens/new.
  2. Fill in Token name: Moment Shop Dashboard config.
  3. Set Expiration to whatever you prefer (1 year is fine).
  4. Change Resource owner from your personal account to momentmotors.
  5. Under Repository access, click Only select repositories, then in the dropdown that appears, pick shop-dashboard.
  6. Scroll down to the Permissions section. A subsection called Repository permissions appears with a long list.
  7. In that list, find the Contents row. Click its Access dropdown (default is No access) and change it to Read and write.
  8. Scroll to the bottom and click Generate token. Copy the token (starts with github_pat_) and paste it above.

Token is saved to this browser only (localStorage). Clear it any time below.
